## Important Workflow Discipline

1. Do not delete or overwrite the previous experiment backup.
2. Development is strictly staged: Act 01 must be completely implemented, browser-tested, and approved by the owner before any subsequent chapter is built.
3. No dependencies or application scaffolding are introduced without explicit owner approval.
4. The site remains 100% silent by default; never autoplay audio or use unlicensed music.
