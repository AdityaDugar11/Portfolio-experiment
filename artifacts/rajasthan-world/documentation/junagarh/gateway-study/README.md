# Suraj Pol gateway quality experiment — incomplete

This original Blender mesh is a work in progress and fails the requested likeness/realism gate. It is not a historically verified reconstruction. The arch opening, two procedural profile bands, wall reveals, passage floor and independent door hinges are editable geometry, not a photograph. The upper recessed arch should be a solid layered facade rather than the current bare outline; the real arch proportions, upper niches, rosettes, fine molding, wall joints and passage are not yet reproduced. Current joints are oversized and repetitive; surrounding walls, sky and materials remain generic. No claim of accurate dimensions, realistic weathering or architectural authenticity is made. Gateway width ~12 m and height ~11 m, and all component dimensions are unverified modeling estimates.

The only locally acquired photograph is [Inde Bikaner Junagarh Fort Suraj Pol](https://commons.wikimedia.org/wiki/File:Inde_Bikaner_Junagarh_Fort_Suraj_Pol_-_panoramio.jpg), rene boulay, 2015, [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/), original unchanged at `references/junagarh/suraj-pol-rene-boulay.jpg`. It appears cropped/resized in the comparison image; the comparison is CC BY-SA 3.0. [Incredible India](https://www.incredibleindia.gov.in/en/rajasthan/bikaner/junagarh-fort) provides architectural context but no imagery was incorporated. More properly licensed, directly comparable front, passage and door photographs remain needed. The single oblique photo is not an overlapping photogrammetry set. [Meshroom/AliceVision](https://alicevision.org/) is open source (MPL-2.0); neither Meshroom nor COLMAP was found on PATH. No appropriate reusable scan was verified in the limited search. No external PBR material was acquired; the current original procedural noise materials are rough placeholders, not verified sandstone or timber texture scans.

`blender/junagarh-gateway-quality-study.blend` and `scripts/build_gateway_quality.py` preserve the separate scene; previous scenes were not modified. Frame 1 shows closed leaves and frame 60 shows an open interpretation. Historical hinge direction and fittings are unverified. Collision clearance has not been tested and should not be assumed; the doorway is missing an accurate door arch. A human-scale reference object (1.7 m) is hidden from rendering. CPU renders use 960 × 720, Cycles 16 samples. Blender's existing OpenColorIO version mismatch falls back to disabled color management; color cannot yet be reliably evaluated. No external asset has been used in the scene and no textures are included.
