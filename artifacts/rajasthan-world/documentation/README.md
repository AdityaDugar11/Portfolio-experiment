# Bikaner terrain proof — incomplete

This is a technical proof of data import, not an approved cinematic Rajasthan world. `blender/bikaner-terrain-draft.blend` contains an editable 240 × 240 mesh from one Copernicus DSM tile and an approximate Junagarh location empty. The empty is not a fort model. The material, camera and lighting are preliminary. The image shows an exposed tile boundary and does not meet the desired visual brief.

Data: Copernicus DEM GLO-90, 2021 release, tile N28 E073, approximately 28–29° N and 73–74° E; 3 arc-second sampling (nominal 90 m). DSM includes structures and vegetation and cannot resolve fort architecture. AWS provides data under the [Copernicus license](https://registry.opendata.aws/copernicus-dem/) and requests citation: “Copernicus Digital Elevation Model (DEM) was accessed on 2026-11-26 from https://registry.opendata.aws/copernicus-dem.” Source: https://copernicus-dem-90m.s3.amazonaws.com/Copernicus_DSM_COG_30_N28_00_E073_00_DEM/Copernicus_DSM_COG_30_N28_00_E073_00_DEM.tif. No external materials or images used. Junagarh's approximate point is not surveyed; verify before use.

Horizontal extent is approximated as 98 × 111 km; mesh coordinates are in kilometers. Vertical relief is multiplied by 10 (and its minimum subtracted) for visibility; this is a deliberate exaggeration, not accurate elevation. The tile was resampled from 1200 × 1200 to 240 × 240, so fine relief is lost. The grid assumes north at top; edges and affine metadata have not been validated for precision. Remaining Rajasthan, other nine fort locations, rivers, roads, vegetation, architecture, camera choreography and real scale are absent.
